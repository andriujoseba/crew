### Added

- `crew reset --cut` snapshots each box as `armed` after proving it is logged in and hired, reclaiming with an on-demand reaper run before it measures the disk and refusing a box still over the ceiling by naming what is large (#589).
- `crew reset` restores each box to its `armed` checkpoint and starts it, refusing a box with no such label rather than falling back to another one (#589).

### Changed

- `crew upgrade` marks the upgraded box's `armed` checkpoint stale in the same write, and `crew reset` refuses that box rather than silently downgrading its engine (#589).
- `crew new --from` refuses an `armed` checkpoint as a clone source: the image carries the source box's credentials and identity (#589).

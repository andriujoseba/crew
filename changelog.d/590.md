### Added

- `shared/host-crontab.example` schedules the fleet host's maintenance: `crew restart --all` daily and `crew reset --all` weekly, one line per job, with no `flock` and no redirect in either line (#590).
- `crew restart` and `crew reset` take one non-blocking host maintenance lock between them, so a daily restart and a weekly reset can never overlap; the later job names the holder, touches no box, and exits 4 (#590).
- `crew restart` and `crew reset` write every run to a host job log, boundary lines and per-box outcomes alike, so a run that did nothing still says so and silence at a boundary means cron is dead (#590).
- `CREW_HOST_STATE_DIR` moves the host maintenance lock and job log together (#590).
- `shared/docs/host-maintenance.md` is the runbook for the two jobs: what a skipped box means, what a refused reset means, and the rule that after any `crew upgrade` you re-cut before the next weekly reset (#590).

### Changed

- `crew restart` and `crew reset` exit 4 when nothing was attempted, distinguishing it from a run in which everything attempted worked (#590).

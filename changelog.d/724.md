  label request's exit status: a fixture an earlier leg closed is reopened
  before any tick fires, and the arming row reds — naming what it read — when
  the re-read does not hold (#724).

  skipped: previous run still holds the lock` is not lane evidence, so the leg
  waits and re-fires within a bound, then reports INCOMPLETE with the reason
  rather than failing a lane it never reached (#724).
- The lane is armed and cleared with the box's own effective
  `LABEL_ATTENTION`, so a box whose operator moved that name is drilled against
  the label its engine actually fetches (#724).
